# Bundesbahnhofsliga

A Bundesliga-style league for German railway stations, ranked only on how punctually ICE and IC trains arrive.
Live at **https://awthura.github.io/bundesbahnhofsliga/**

Each day is a matchday. A station's points for the day are the share of its scheduled ICE/IC arrivals that were
less than 6 minutes late (cancelled counts as late), so 0.00 to 1.00. A station plays a day only with more than 5
arrivals, and is a league member only if it had more than 5 arrivals on every day of the previous 28. A season is one calendar week; the table updates after every matchday and promotion/relegation happens
after Sunday. The 1., 2. and 3. BBL are national with 18 stations each; below them are five Regionalligen by region
(Nord, Nordost, West, Südwest, Bayern). 17th and 18th go down, 1st and 2nd of the league below go up, and 16th vs
3rd is a playoff decided by punctuality on Sunday; into the 3. BBL the Regionalliga champions play an Aufstiegsrunde. Full rules: [docs/rules.html](docs/rules.html).

## How it works

```
Hugging Face piebro/deutsche-bahn-data        (DB Timetables API, CC BY 4.0)
  monthly processed parquet  ─┐
  raw hourly API dumps       ─┼─> bbl/ingest.py  -> data/stops/<day>.parquet   (one row per ICE/IC arrival)
our collector (optional)     ─┘                        │
                                                       v
                              bbl/points.py   -> data/daily_points.csv       (in git, the source of truth)
                              bbl/league.py   -> weekly seasons, tables, moves, playoffs
                              scripts/build_site.py -> docs/data/*.json -> GitHub Pages (docs/)
```

GitHub Actions (`.github/workflows/update.yml`) runs every 3 hours: fetch new days, run tests, rebuild, commit.
The storage server (Hetzner) is an optional archive for the per-day stops and our own collector's raw API dumps;
see [ops/SERVER.md](ops/SERVER.md). All credentials live in GitHub Actions secrets, never in the repo.

## Run locally

```sh
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m scripts.update_data --months 2026-10      # a complete month
.venv/bin/python -m scripts.update_data --days 2026-11-01 2026-11-14
.venv/bin/python scripts/build_site.py
.venv/bin/python -m pytest -q
cd docs && python3 -m http.server 8000                        # open http://localhost:8000
```

Downloads go to `data/raw/` (gitignored) and are deleted after parsing unless `--keep-raw` is passed.
Rules and thresholds are all in `bbl/config.py`. Crests are generated by `scripts/make_logos.py`.

## Data and attribution
